# MEGAPOLIS MEBEL — Сандуқ конструктори

Mobile-first статик веб-илова. Асосий файл: `sandiq-app/index.html`.

## Ҳозирги имкониятлар
- Three.js асосидаги интерактив 3D сандуқ геометрияси
- 360° айлантириш, яқинлаштириш, ўлчамлар
- Мато тури, ранг ва қоплама услуби
- Хизматлар ва тахминий нарх ҳисоблаш
- Буюртма маълумотини Telegram орқали тайёрлаш
- Демонстрацион админ нарх панели

## Муҳим чекловлар
Бу биринчи frontend босқичи. Админ нархлари ҳозирча браузернинг localStorage'ида сақланади. Telegram тугмаси Telegram чатини очади ва мижоз хабарни ўзи юборади. D1 маълумотлар базасига буюртмаларни сақлаш, серверда ҳимояланган админ авторизацияси ва бот орқали автоматик хабар юбориш ҳали интеграция қилинмаган. Парольни frontend ичида сақлаш хавфсиз эмас.

Cloudflare Pages'да deploy қилиш учун Build command'ни бўш қолдиринг ва Root directory сифатида `sandiq-app` ни белгиланг. Бу репозиторийнинг бошқа `main` тармоғини ўзгартирмайди; ушбу иш алоҳида `megapolis-sandiq-app` тармоғида.
